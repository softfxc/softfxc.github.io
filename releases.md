## Nympo

Nympo es una herramienta de consola escrita en C++ para empaquetar, desempaquetar, listar, comprobar y convertir paquetes en lanzadores autoextraíbles.

## Wynemo

Wynemo es una app Android escrita en Kotlin con módulo nativo C/C + +. El proyecto combina tres partes: biblioteca de perfiles de OS, inspección de ejecutables Windows PE y ejecución mediante runtimes gestionados.

## Hydra

Hydra es una adaptación para Android de Hydra Launcher. El código conserva el renderer web/React y sustituye el IPC de Electron por un puente Android/WebView.

## DownTV

DownTV es una aplicación Android de catálogo y reproducción multimedia.

## Coqui TTS

XTTS es una aplicación de síntesis de voz basada en Coqui y Gradio.

## FitGirl-Repack Installer

FitGirl Installer es una plantilla de instalador Windows en Inno Setup.

## Render 3D

El paquete `render.zip` contiene una cadena de scripts para Blender orientada a crear, materializar, animar, renderizar y codificar en vídeo una escena.
